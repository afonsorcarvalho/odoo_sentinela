# Sentinela — regras do projeto

## TODO.md é obrigatório e sempre atual

- Toda tarefa concluída, deployada ou descoberta entra no `TODO.md` **no mesmo commit/turno** em que acontece — nunca "depois".
- Concluiu algo → move para **Feito** com data (AAAA-MM-DD), resumo de uma linha e commit.
- Começou algo → **Em curso**. Descobriu pendência/bug/follow-up → **Pendente**.
- Antes de encerrar qualquer turno com mudança de código ou deploy, conferir o `TODO.md` e atualizar.
- TODO desatualizado é falha, não detalhe.
